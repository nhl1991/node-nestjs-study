

npm i로 패키지 설치 시 dependency에 의존성 패키지 목록들이 작성 됨.

### [major].[minor].[patch] 3개의 숫자로 버전을 나타냄.
- major는 하위호환 되지 않는 변경 사항
- minor는 하위호환 되는 변경 사항
- patch는 간단한 버그 수정
- package 버전 앞에 ~나 ^ 같은 기호가 붙음
- ^ 는 minor 버전까지만 설치하거나 업데이트 함. 어떤 패키지가 @^1.2.5 라면 @2.0.0 미만의 버전까지만 설치함.
- ~ 는 patch 버전까지만 설치하거나 업데이트 함. 어떤 패키지가 @~1.2.5 라면 @1.3.0 미만의 버전까지만 설치함.
- 이외에도 >, <, >=, <=, = 를 사용 할 수도 있음. 각각 초과, 미만, 이상, 이하, 동일을 뜻함 @>1.2.5 처럼 사용 



### npm version 관리

- npm version 명령어를 통해 패키지의 버전을 수정할 수 있음
- npm version major | minor | patch 로 각각 1씩 올릴 수 있음.
